## Reference materials

The uploaded textbooks, course notes, JWAS snapshot and teaching R code were
used as **references only**. Formulas were re-derived and checked
(`docs/methods.md`); no code was copied. Example 01 uses the five-record
teaching data of Mrode (2005), Example 3.1, cited as a fact-based test case.
The synthetic sheep data were generated by ABP and carry no third-party
rights.
